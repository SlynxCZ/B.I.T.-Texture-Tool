B.I.T. Texture Tool V0.17.16 - Build instructions

Language: Go (Golang)
Target: Windows x64 GUI

From this folder, build with:

  set GOOS=windows
  set GOARCH=amd64
  go build -ldflags="-H=windowsgui" -o BIT_Texture_Tool_V0.17.16.exe main.go

From Linux/macOS with Go installed:

  GOOS=windows GOARCH=amd64 go build -ldflags='-H=windowsgui' -o BIT_Texture_Tool_V0.17.16.exe main.go

The PNG files are UI assets used by the application.
